# Editorial triage

## Load when
Starting any review, deciding severity, or deciding whether later polish matters.

## Questions answered
What fails first? Is the draft viable? Which defects block acceptance?

## Method
1. Compare immutable input, draft identity, and pass type.
2. Test grounding and safety before stylistic quality.
3. Test brief alignment, platform limits, and CTA next.
4. Test voice and clarity only on a viable candidate.
5. Mark every observed dimension independently; one pass cannot excuse another failure.
6. Prefer the smallest issue set that completely describes material defects.

## Required inputs
Exact draft, brief, selected item, evidence, constraints, pass type, and prior review.

## Expected contract effect
Seven complete checks, calibrated severity, and a consistent accept-or-revise verdict.

## Failure modes
Line-editing a fatally ungrounded draft, vague quality judgments, contradictory checks, or perfectionism that invents defects.

## Evidence and authority
Triage changes review order only. It supplies no evidence and cannot accept an external effect.
