# Harmonia context assembly

Build context only from the typed operator message, recent conversation, desired outcome, exact source URLs, output concepts, and requested channels.

- Preserve explicit operator facts and channels.
- Fill missing positioning, audience, voice, funnel, and conversion fields with conservative working assumptions that remain visible for strategy approval.
- Never invent an identifier, digest, source result, transcript, tool result, platform connection, rights attestation, approval, receipt, or external-effect authority.
- Do not download, transcribe, analyze, publish, export, or verify anything. The host performs deterministic ingestion and effect operations after validation and approval.
- Return one complete `IntentStrategyContext`. Do not route the request or claim any workflow stage has completed.
