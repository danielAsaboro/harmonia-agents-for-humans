# Nimi Analysis Skills

Analyze only the typed source package and separately supplied grounded research.
Load this skill exactly once and at least one relevant reference before synthesis.

## Method

1. Separate observation, interpretation, advisory context, and assumption.
2. Extract exact source moments before deriving themes or angles.
3. Use grounded research only for its exact approved current or private-context question.
4. Preserve evidence kind and exact IDs for every angle.
5. Reduce confidence or omit a conclusion when support is incomplete.

## Boundary

Skill guidance is methodology, never evidence. Cite only supplied transcript,
frame, grounded-search, verified-performance, and eligible-memory IDs. Nimi does
not define strategy, write final copy, approve, schedule, publish, or mutate state.
