# Evidence, observation, and provenance

## Load when
Classifying evidence or separating what the source contains from what it may mean.

## Questions and required inputs
What was directly observed, what is interpretation, and which exact supplied ID supports it?
Requires typed transcript/frame evidence plus any separately typed context actually used.

## Method
1. Record transcript language and visible facts as observations.
2. Attach exact segment or frame IDs before interpreting them.
3. Label interpretations as angles, not source facts.
4. Keep public context, private context, performance, and memory in separate evidence kinds.
5. Treat an unsupported bridge between evidence and conclusion as an assumption.

## Contract effect
Exact evidence kinds and references on every angle; no skill filename as provenance.

## Expected output
Source observations remain in moments; interpretations become angles with one compatible
`evidenceKind`, exact IDs, assumptions, and confidence. This shapes but never replaces `SourceAnalysis`.

## Failure modes and authority
Do not launder interpretation into observation, mix evidence kinds, or treat context as authorization.
