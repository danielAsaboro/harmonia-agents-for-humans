# Performance and memory interpretation

## Load when
Verified outcomes or eligible Memory Bank facts may qualify an observation.

## Questions and required inputs
What was verified before, how comparable is it, and what is only a prior belief or preference?
Requires tenant-scoped verified performance IDs or eligible fact IDs with Firestore provenance.

## Method
1. Confirm the exact performance or memory ID and its evidence kind.
2. Describe the observed association without inventing causality.
3. Check whether the prior context actually matches the current source.
4. Use memory as a prior learning or preference, never as source proof.
5. Record mismatch or weak transfer as an assumption and reduce confidence.

## Contract effect
Performance or memory learning angles with distinct provenance.

## Expected output
A qualified learning `Angle`, never an authorization, causal claim, policy exception, or source fact.

## Failure modes and authority
Do not fabricate metrics, generalize one outcome, treat preference as research, or use memory to authorize an action.
