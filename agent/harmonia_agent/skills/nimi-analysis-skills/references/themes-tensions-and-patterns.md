# Themes, tensions, and patterns

## Load when
Several observations may form a theme, contradiction, mechanism, or meaningful variation.

## Questions and required inputs
What mechanism connects the observations, what contradicts it, and how broad is the support?
Requires two or more atomic supplied observations for a pattern claim.

## Method
1. Make each observation atomic before grouping.
2. Cluster by shared mechanism or question, not superficial vocabulary.
3. Name what the cluster explains and cite its component evidence.
4. Preserve counterexamples, qualifications, and isolated observations.
5. Prefer one defensible pattern over several synonymous themes.

## Contract effect
Concise summaries and source insights whose logic is visible from cited evidence.

## Expected output
A bounded summary or `source_insight` angle, still expressed through the strict output contract.

## Failure modes and authority
Do not force frequency from a single source, erase contradiction, or convert a theme into a campaign decision.
