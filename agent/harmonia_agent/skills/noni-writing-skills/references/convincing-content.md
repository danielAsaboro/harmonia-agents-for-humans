# Convincing, Credible Content

Readers trust writing that feels observed rather than manufactured.

- Use concrete supplied details where they materially clarify the point.
- Preserve the operator's real voice and degree of certainty.
- Make claims proportional to evidence and name relevant limitations.
- Prefer one credible proof point to several unsupported assertions.
- Remove borrowed authority, inflated emotion, synthetic anecdotes, and vague
  claims that could describe any company.

Run a final authenticity test: could this exact piece be written without the
supplied source, brief, and brand context? If yes, make it more specific using
only those inputs—not general knowledge.
