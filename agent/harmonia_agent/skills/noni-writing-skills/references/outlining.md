# Outlining

Outline before drafting when the format has multiple beats or the argument is
easy to muddle.

- Write the one-sentence controlling idea.
- Define the reader change: know, believe, feel, or do.
- Assign each beat a distinct purpose.
- Attach supplied evidence to the beat it supports.
- Place the strongest payoff early and the approved CTA where it follows
  naturally.
- Remove any beat that repeats another or lacks evidence.

For a single short post, use a micro-outline: hook → proof → implication → CTA.
The outline is private reasoning and must not appear as workflow metadata.
