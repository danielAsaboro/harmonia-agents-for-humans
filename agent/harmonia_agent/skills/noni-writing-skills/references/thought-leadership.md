# Thought Leadership

Thought leadership gives the reader a defensible way to think, not a generic
list of actions. Build it from an earned perspective already present in the
supplied evidence: a hard problem solved, a surprising observation, a grounded
counter-narrative, a personal operating lesson, industry analysis, or verified
data insight.

- State the recognizably specific perspective.
- Show the experience or evidence that earned it.
- Connect it to a consequence the audience cares about.
- Prefer useful provocation over contrarian performance.
- Do not claim authority; let specificity and proof demonstrate it.

If the input contains no earned perspective, write useful evidence-led content
instead of manufacturing thought leadership.
