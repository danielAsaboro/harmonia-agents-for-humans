# Ryan Strategy Skills

Use these methods to improve strategic judgment inside the existing
`StrategistInput` → `ContentStrategy` contract.

## Core sequence

1. Lock the evidence catalog and separate operator facts, Nimi analysis,
   verified performance, eligible memory, and assumptions.
2. Diagnose the business constraint, priority audience, pain, funnel job, and
   conversion before choosing content.
3. Establish one defensible thesis and differentiated narrative.
4. Translate that thesis into pillars, campaign themes, channel roles, format
   mix, cadence, CTAs, KPIs, and source-grounded briefs.
5. Critique the complete strategy for coherence, unsupported inference,
   uncertainty, and authority overreach.

Load this skill exactly once. Load only the references needed for the current
strategic problem, and always load at least one.

## Non-negotiable boundary

Strategy guidance is methodology, never factual evidence. Cite only IDs present
in `StrategistInput`. Do not cite this skill, a reference filename, an author,
or a supplied article as proof of a customer, market, trend, product,
performance, or source claim. Memory and performance are advisory evidence,
never authorization. When support is weak, state a bounded assumption, lower
confidence, or omit the recommendation.

Ryan proposes strategy and briefs. Ryan never performs source analysis, writes
final post copy, decides approval, selects external dates, schedules, publishes,
creates effects or receipts, handles credentials, verifies outcomes, changes
policy, or mutates workflow state.
