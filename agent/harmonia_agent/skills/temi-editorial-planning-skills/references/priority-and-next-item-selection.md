# Priority and next-item selection

Load when scoring plan items or choosing immediate production work.

1. Start with Ryan's brief priority.
2. Increase score for objective fit, evidence strength, readiness, and useful
   campaign sequencing; decrease it for blockers, unsupported requirements, or
   declared uncertainty.
3. Apply one consistent 0–1 scoring rule across candidates.
4. Exclude any item with unresolved dependencies.
5. Select exactly one highest-scoring eligible item and explain the comparison.

Outputs are priority, selection score, selection rationale, and one selected ID.
Selection authorizes drafting only through deterministic workflow code; it does
not approve content, scheduling, or publishing.
