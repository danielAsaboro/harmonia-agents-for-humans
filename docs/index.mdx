title: "Harmonia"
description: "Autonomous social media content engine for startups — video in, verified posts out."
---

Harmonia turns raw material — a YouTube video or a plain topic brief — into drafted, approved, published, and **independently verified** social media posts. It runs asynchronously in the background, proposes ideas on its own, and never publishes without explicit operator approval.

## What makes it agentic

- **Autonomous pipeline**: ingest → transcribe → understand → draft runs end-to-end via Pub/Sub with persisted, resumable job state
- **Proactive intelligence**: a background agent scans trends and your own engagement metrics on a schedule and proposes topics *with reasons and sources* (see [Proactive Agent](/proactive-agent))
- **Meaningful action**: it publishes to X through the official API, renders real media with ffmpeg, and exports content packs
- **Human-in-the-loop**: publishing, scheduling, and proposal acceptance all pass through explicit approval gates
- **Auditable**: every external effect produces an idempotent receipt and an independent verification record

## The short version

1. An operator drops a YouTube URL into chat (dashboard or Telegram), or approves one of Harmonia's own topic proposals
2. Gemini 3.5 transcribes the video, finds clip-worthy moments, trend angles, and meme angles
3. A Google ADK planner drafts posts and proposes actions: publish to X, render captioned vertical clips, generate meme images, export a content pack
4. Everything pauses at an approval gate. The operator approves, rejects, or schedules
5. Approved actions execute with idempotency keys; every result is re-fetched independently and recorded as verification evidence
6. Engagement metrics flow back into future ideation

## Stack

| Layer | Technology |
|---|---|
| Model | Gemini 3.5 Flash (via google-genai) |
| Agent framework | Google ADK (planner agent) |
| Web app | Next.js App Router |
| Worker | Python FastAPI + background threads |
| State | Cloud Firestore |
| Messaging | Pub/Sub stage triggers |
| Media | ffmpeg (cuts, reframes, captioned clips, reels) |
| Publishing | X API v2 |
