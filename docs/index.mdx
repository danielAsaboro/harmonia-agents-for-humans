Harmonia turns authorized source material into a durable social-content job: understand the source, draft platform-native assets, wait for authority, execute an exact effect, and independently verify the result. Ambiguous creative work belongs to Google ADK agents; workflow truth, authority, cost, and side effects remain deterministic.

<Warning>
  **Evidence status (August 26, 2026):** repository behavior and the local Firestore/Pub/Sub workflow have automated evidence. The reachable Cloud Run revision is a web-only preview. It does not prove a deployed worker, Scheduler, Agent Engine invocation, Memory Bank retrieval, or live publish. Use the [evidence runbook](/evidence-runbook) before making any authenticated-cloud claim.
</Warning>

## What is implemented

- **Bounded autonomous pipeline**: ingest → transcribe → understand → draft is designed to run through recoverable Pub/Sub stages with Firestore as workflow truth
- **Proactive intelligence**: a background agent scans trends and your own engagement metrics on a schedule and proposes topics *with reasons and sources* (see [Proactive Agent](/proactive-agent))
- **Meaningful action adapters**: official X publishing, real ffmpeg rendering, and content-pack export are bounded behind typed effect contracts
- **Human authority**: consequential effects require an exact approval or an operator-created durable mandate whose evaluated payload is bound into the command
- **Auditable**: publishing and export effects produce idempotent receipts and independent verification; Calendar mutations retain their latest verified projection or verified absence on the content item
- **Calendar-aware**: scheduled content can be explicitly synchronized to an app-created Google Calendar without exposing unrelated calendars

## The short version

1. An operator submits an authorized YouTube URL or upload in the dashboard; Telegram's webhook boundary exists in code but is not yet live-evidenced
2. Gemini 3.5 transcribes the video, finds clip-worthy moments, trend angles, and meme angles
3. Harmonia delegates to Ryan and Sophia, then Flo runs Nimi → Dara → Temi before proposing gated actions
4. Proposed consequential effects wait for an exact approval or a matching durable mandate. Natural-language approval only opens the deterministic confirmation flow
5. Approved actions execute with idempotency keys; every result is re-fetched independently and recorded as verification evidence
6. Engagement metrics flow back into future ideation

## Stack

| Layer | Technology |
|---|---|
| Models | Gemini 3.5 Flash / Flash-Lite plus Gemma 3 12B IT, selected by role policy |
| Agent framework | Google ADK (coordinator, specialists, sequential review workflow) |
| Web app | Next.js App Router |
| Worker | Python FastAPI on Cloud Run; Pub/Sub push plus Scheduler OIDC tick |
| State | Cloud Firestore |
| Messaging | Pub/Sub stage triggers |
| Media | ffmpeg (cuts, reframes, captioned clips, reels) |
| Publishing | X API v2 |
