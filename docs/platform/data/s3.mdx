## How Harmonia uses it


Uploads enter tenant-scoped quarantine, pass authenticated malware scanning, then promote to sealed source objects. Generated media, exports, and large records use immutable keys. Verification reads the stored bytes and recomputes SHA-256. Retained external GCS libraries are source connectors, not internal storage.
