## How Harmonia uses it

ffmpeg performs deterministic cuts, captions, reframing, and reel assembly from sealed production plans. Vertex generative media can create images, video, or audio only through explicit supported actions and the same budget and approval boundaries as other effects. Production plans are versioned, source-grounded, costed, sealed, and approved before paid operations enter the production outbox.
