## How Harmonia uses it

Amazon Transcribe provides word-timed speech evidence. Nova 2 Lite analyzes the supplied source evidence. Approved production requests can use Nova Canvas images, Nova Reel asynchronous video and ElevenLabs instrumental music. ffmpeg and HyperFrames assemble authorized media from sealed plans.

The host owns asset identities, generation costs, approval digests, claims and receipts. Models propose content and cannot invoke these external effects directly. Export availability does not claim that any current asset or provider has been verified.
