## How Harmonia uses it


OpenTelemetry correlates request, job, operation, and provider execution metadata. Container logs are sent to CloudWatch. Prompt bodies, transcripts, drafts, credentials, and chain-of-thought must not enter telemetry. A successful local test does not constitute a deployed trace.
